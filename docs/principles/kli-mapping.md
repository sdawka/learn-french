# KLI Framework → Game Type Mapping

The Knowledge and Learning Instruction (KLI) framework classifies knowledge into four types, each requiring different instructional strategies.

## KLI Types and Instructional Principles

| KLI Type | Acquisition Method | Instructional Strategy |
|---|---|---|
| **Fact** | Recall + spaced repetition | Drill → retrieval practice → spacing |
| **Concept** | Classification + discrimination | Category examples, contrast pairs |
| **Procedure** | Worked example → guided → independent | Fading scaffolding, step-by-step breakdown |
| **Principle** | Transfer + error correction | Novel contexts, near/far transfer tasks |

---

## Vocabulary Game Mapping

| Game | KLI Type | Hardest → Easiest Scaffold |
|---|---|---|
| **Translate** | Fact | Free type → first-letter hint → MC-2 → MC-4 |
| **Cloze** | Fact + Concept | Typed → partial hint → MC options |
| **Definition** | Concept | Typed French → MC French definitions |
| **Odd-one-out** | Concept | No category label → category shown |
| **Idiomatic sentence** | Principle | MC-4 → MC-2 → rule explanation shown |
| **Context guess** | Principle | Long passage → short passage → MC |

**Why these pairings:**
- Translate/Cloze target **Facts** because they require direct retrieval of form-meaning pairs — exactly what SRS excels at reinforcing.
- Definition/Odd-one-out target **Concepts** because they require classification: is this word in the same semantic field as these others?
- Idiomatic/Context-guess target **Principles** because idiomatic usage and contextual appropriateness require _transfer_ — applying knowledge to novel situations, not just rote recall.

## Grammar Game Mapping

| Game | KLI Type | Hardest → Easiest Scaffold |
|---|---|---|
| **Construct** | Procedure | MC-6 → MC-4 → MC-2 |
| **Transform** | Procedure | Independent → guided steps → worked example first |
| **Spot error** | Procedure + Principle | No hint → error region highlighted |
| **Dictogloss** | Procedure + Fact | From memory → audio+text → with transcript |
| **Naturalness** | Principle | 5 options unranked → pre-sorted options |

**Why these pairings:**
- Construct/Transform target **Procedures** because forming grammatically correct output is a procedural skill (conjugation, agreement). These benefit from worked examples (explicit rule + steps) before independent production — Sweller's Cognitive Load Theory.
- Spot-error crosses Procedure + Principle: identifying an error requires both knowing the rule (procedure) and applying it to judge a novel sentence (principle).
- Naturalness targets **Principles** by asking "which is most natural?" — a transfer task requiring pragmatic and register awareness beyond rule knowledge.

---

## Scaffold Design Rationale

Scaffold level 0 (hardest) is always the _instructional target_ — the form of the task a fluent speaker would encounter. Lower scaffolds add support to reach that target:

- **Multiple choice options** reduce retrieval demand to recognition (easier than recall)
- **Hints** reduce working memory load
- **Worked examples** externalize the procedure, letting the learner observe before producing
- **Category labels / rule explanations** provide explicit schema to anchor new information

The scaffold fades toward 0 as the learner demonstrates competence. This is direct implementation of **fading** from Cognitive Apprenticeship (Collins et al., 1989).

## What We Don't Do (and Why)

- **No gamification points/streaks as primary motivation:** Extrinsic rewards undermine intrinsic motivation (Deci & Ryan, 1985). Streaks are tracked but not emphasized.
- **No random item selection:** All scheduling is FSRS-driven to maintain the optimal retention window.
- **No purely blocked practice:** Grammar drills interleave multiple categories per session (interleaved practice +30% transfer, Kornell & Bjork 2008).
